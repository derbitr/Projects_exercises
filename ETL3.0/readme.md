Projeto de ETL (Extract, transform and load) para fixaçao de conceitos de engenharia de dados, arquitetura limpa e modularização

m1banco: Criação do banco de dados utilizando sqlite

m2modelos: Especificação de busca de dados com pydantic e lógica de programação para busca de valores

m3extrator: Lógica de extração de dado para tratamento de erros

m4main: Arquivo principal para rodar toda a infraestrutura do código
