Python Mini E-Market System

Project Overview:

This is a functional Command Line Interface (CLI) e-commerce application developed in Python. It simulates a complete shopping experience, from product selection and inventory management to cart calculation and checkout.

Key Features:

Interactive Shopping Cart: Users can browse a product list, add items to a virtual cart, and manage quantities.
Dynamic Pricing & Discounts: Integrated logic to apply automatic discounts based on payment methods 
Inventory Control: A structured data approach to manage product availability and prices.
Formatted Checkout: Generates a clean, readable receipt showing the total investment, applied discounts, and final balance.

Technical Skills Demonstrated
 **Data Structures:* Efficient use of lists and dictionaries to store product information.
 **Control Flow:* Robust implementation of `while` loops and `if/else` statements for a seamless user experience.
 **Input Validation:* Handling user choices to ensure the system doesn't crash during the shopping process.
Clean Code:Organized logic that separates product display from financial calculation.
